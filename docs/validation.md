# 已验证能力与发布门槛

0.3.0-rc.1 已完成当前 Windows 宿主的本地候选验收；现作为预发布版发布。首发范围为 Windows x64 + Codex + Docker Desktop/WSL2，以及当前方法兼容的 AES-128 C 接口。

| 验收项 | 当前结果与范围 |
|---|---|
| 程序回归 | 最终候选镜像 85/85，包含原有 67 项以及任务、导出、保留策略和路径行为 |
| Windows 调用 | PowerShell 5.1 下 13 项、专用 PowerShell 下 12 项，均通过；重启返回值边界另以合成子进程验证，不重启机器 |
| 新任务流程 | 普通 AES 完整 pilot 10 条；用户同意后正式 100 条，独立留出 16/16；原始输入和本次全部运行数据保留 |
| 结果来源 | 既有 CPA 重新提取候选与记录一致，最终运行代码与执行快照摘要一致，独立验证仍为 16/16；复核不计新恢复样本 |
| 离线安装 | 中文、空格、逗号及单引号目录安装、完整性检查、重复安装和原卷保留通过；缺失运行时诊断和独立修复通过 |
| 发行边界 | 固定 ZIP 逐项核对全部 130 个成员，正式安装的 129 个清单文件匹配；未安装检查退出 2、错误 ZIP 摘要退出 40，均不创建目标 |
| 本机迁移 | Docker 程序、实际数据盘和专用运行时迁至 D 盘；冷备份完整解压摘要校验通过，旧 Docker 两次实验共 322 个原件校验无误 |
| 新聊天 | 实际新聊天加载已安装两个 Skill，通过缓存入口调用 doctor、既有运行 status 和 history，最终调用方退出 0；首次隔离拒绝单独保留 |

历史 RC3 普通 AES 的 10/100/16 与 WhibOx #47 的 50/500/16 均为独立验证 16/16，回归 67/67；原生三种子及失败原件继续保留在本地。#47 本轮仅核验既有证据和历史，未追加实验；#82 继续跳过。

逐项记录、实际路径、原始失败尝试、用户选择、空间采样及迁移索引保存在私有数据目录。发行 ZIP 的摘要和可公开的简短本机验收说明单独随本地发行附件交付，不把研究原件或用户授权放入源码 Git。

稳定版验收仍需完成真实干净 Windows 上从 GitHub 获取插件、首次补齐缺失环境并完成赛题流程。预发布版会分别记录公开下载、GHCR 和 CI 验证，不能代替干净 Windows 运行。客户端插件页独立 Setup 按钮、“立即试用”跳转和结果卡片未在本轮观察；另一宿主和 Linux 宿主入口分别验收。历史 `full_stage_d_accepted=false` 保持不变。

环境 ready、合成测试通过、实际恢复、新聊天 Skill 调用和公开安装是不同证据。未运行或未观察的项目记录为待验收，不推定成功。
